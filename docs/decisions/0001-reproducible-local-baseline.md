# Reproducible local baseline

## Decision

Start with a small synthetic aggregate fixture and one dependency-light local workflow before using approved disclosures.

## Why

This proved schema, metric, control, UI, and evaluation contracts without distributing restricted data or hiding basic defects behind a large pipeline.

## Alternatives rejected

- Begin with full disclosure archive: slower feedback and unnecessary data exposure during contract design.
- Build hosted services first: no measured need and avoidable cost.

## Not done

Synthetic results were never presented as Freddie Mac performance evidence.

## Changed

Created reproducible baseline, local workflow, tests, and first-demo readiness evidence used by M1 through M3.
