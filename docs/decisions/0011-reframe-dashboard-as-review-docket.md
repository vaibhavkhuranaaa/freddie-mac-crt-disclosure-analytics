# Decision 0011: Reframe the public dashboard as a review docket

Status: accepted on 2026-08-17.

## Decision

Replace the generic dashboard presentation with a monthly risk-committee review docket. Keep the verified metric workflow and public aggregate boundary unchanged.

## Why

The prior interface was usable but read like a template: a broad slogan, repeated bordered modules, familiar teal accents, and interchangeable evidence cards. It did not express the specific job of reviewing a monthly collateral file.

The replacement uses the visual language of a filed committee packet: a dated cover sheet, numbered review sections, registration-black rules, restrained status ink, condensed headings, and compact evidence stamps. The opening frame identifies the current disclosure, source coverage, method, release boundary, and analyst task before presenting the queue.

## Constraints retained

- Public aggregate output only, with no borrower-level data.
- Same metric definitions, filters, findings, evidence, and restricted drill-through boundary.
- No runtime API, database, secret, or restricted asset in the static release.
- Responsive operation, keyboard access, readable focus states, and reduced-motion behavior.
- No unsupported predictive, causal, investment, or representative-usability claim.

## Consequence

The product now has a recognizable risk-review frame without changing the analytical contract. New screenshots and browser evidence are required before promotion because the interface changed materially.
